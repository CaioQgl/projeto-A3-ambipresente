# AmbiPresente - Aplicativo de Conscientização Ambiental

## Sobre o Projeto
O AmbiPresente é uma plataforma com o objetivo de ensinar sobre
hábitos sustentáveis de forma interativa e participativa a partir de tarefas diárias e
jogos funcionais, utilizando IA como auxílio.
